VirtualBox generates virtual MAC addresses by combining a fixed vendor prefix with three randomly generated bytes.

The Structure

• The Prefix (OUI): The first three bytes (24 bits) are always set to 08:00:27. This Organizationally Unique Identifier (OUI) historically belonged to Innotek GmbH (the original creator of VirtualBox) or PCS Systemtechnik / Cadmus, but is universally recognized by network tools as an Oracle VirtualBox Virtual NIC.
• The Random Suffix: The remaining three bytes (24 bits) are generated randomly using a pseudo-random number generator when a new virtual machine or network adapter is created.
